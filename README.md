# Character Studio

Character-consistent animation studio for faceless YouTube channels.
A character is data, not a picture.

## Status

- M0a — repo + deploy live. Landing page only.
- Next: parametric character model + SVG renderer (ported from the
  Python + SVG reference engine), 5–6 poses, 5–6 expressions, live
  slider page.

## Stack

Next.js 14 (App Router) + TypeScript + Tailwind CSS. Free tiers only —
Vercel free, Supabase free (later). No paid APIs. Rendering client-side.

## Develop

```bash
npm install
npm run dev
```
